# Worth It

A fun, celebratory gym tracker. Enter what you pay each month and tick off every session: it shows what each session has really cost you, how you're doing against your weekly goal, and what to train next, with lots of praise along the way.

- Google sign-in, a private space per person, invite links for friends
- Works offline (Firebase offline cache + service worker), installable on the home screen
- Plain HTML/CSS/JS, hosted on GitHub Pages

See **[SETUP.md](SETUP.md)** to set up Firebase and GitHub Pages. Try it without setup: open `index.html` through any web server with `?demo` (or `?demo&sample` for made-up history).

Fonts: Baloo 2 and Nunito (SIL Open Font License), included in `fonts/`.
